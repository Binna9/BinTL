# OpenWiki brief

Human-authored docs live in `/docs`. Treat `/docs` as the product contract. Do not hand-edit generated wiki pages to change product rules.

Do not create, update, or restore root `AGENTS.md` or `CLAUDE.md`. This repository does not use those agent entry files. Leave them absent. If a previous OpenWiki run added them, delete them on the next finish rather than rewriting the OpenWiki block.

Keep generated pages aligned with `/docs` and current source. Prefer Korean for page prose.
